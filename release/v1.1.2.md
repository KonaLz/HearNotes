# HearNotes 1.1.2 / 听记 1.1.2

## 中文

此版本用于从 HearNotes 1.1.1 实际验证新版软件更新流程。

### 验证内容

- 下载期间显示进度弹窗。
- 显示下载百分比、已下载大小、总大小和下载速度。
- 显示检查版本、下载、签名验证、关闭后台和启动安装程序等阶段。
- 安装前结束转写引擎及 worker 进程树，等待文件句柄释放。
- NSIS 安装器在更新模式下执行第二道后台清理。

### 安装与更新

- 已安装 1.1.1：进入“模型与更新”检查更新，然后点击下载并安装。
- 首次安装：下载下方的 `HearNotes_1.1.2_x64-setup.exe` 并运行。
- 软件更新使用数字签名验证，用户电脑不需要 GitHub Token。

## English

This release verifies the new application update flow from HearNotes 1.1.1.

### Verification scope

- Show an update progress dialog during the download.
- Display percentage, downloaded size, total size, and transfer speed.
- Display the version check, download, signature verification, background shutdown, and installer launch stages.
- Stop the transcription engine and worker process tree before installation and wait for file handles to be released.
- Run a second background cleanup from the NSIS installer in update mode.

### Installation and update

- Existing 1.1.1 installation: Check for updates under “Models & Updates,” then select download and install.
- New installation: Download and run `HearNotes_1.1.2_x64-setup.exe` below.
- Application updates are verified with a digital signature. No GitHub token is required on user computers.
