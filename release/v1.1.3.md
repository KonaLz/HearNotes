# HearNotes 1.1.3 / 听记 1.1.3

## 中文

本次更新重点改善日语界面，并修复转写进度不会跟随界面语言切换的问题。

- 全面润色日语界面文案，使按钮、提示和状态说明更符合日本桌面软件的表达习惯。
- 转写进度标题、GPU 回退提示、录音语言名称和模型更新阶段会随中文、日文、英文界面即时变化。
- 默认说话人名称统一为 `Speaker A`、`Speaker B` 等英文形式，不确定项统一为 `Needs review`。
- 用户自行输入的姓名不会被界面语言切换覆盖。
- 修复切换界面语言时“未保存”状态被重置的问题。
- 兼容旧版本保存的中文进度阶段和默认说话人名称。

### 安装与更新

- 已安装旧版本：可在“模型与更新”中检查并安装 1.1.3。
- 首次安装：下载下方的 `HearNotes_1.1.3_x64-setup.exe` 并运行。
- 语音转写和说话人分离模型仍需在软件内单独下载。

## English

This release improves the Japanese interface and fixes live progress text that did not follow the selected display language.

- Reworked Japanese buttons, guidance, and status messages for natural, consistent desktop-app wording.
- Live transcription stages, GPU fallback notices, recording-language names, and model-update stages now update with the Chinese, Japanese, or English interface.
- Standardized untouched speaker labels as `Speaker A`, `Speaker B`, and `Needs review` across all display languages.
- Names entered by the user remain unchanged when the interface language changes.
- Preserved the unsaved-edit state when switching display languages.
- Kept compatibility with progress records and default speaker names created by older versions.

### Install and update

- Existing installation: Check for version 1.1.3 under Models & updates.
- New installation: Download and run `HearNotes_1.1.3_x64-setup.exe` below.
- Transcription and speaker-separation models are still downloaded separately inside the app.
