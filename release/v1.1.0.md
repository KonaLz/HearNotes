# HearNotes 1.1 / 听记 1.1

## 中文

此版本用于验证从 HearNotes 1.0.2 自动更新到 1.1 的完整流程。

### 更新内容

- 桌面界面改为使用 Tauri 内置资源，修复软件更新命令无法从本机 HTTP 页面调用的问题。
- 软件启动时默认联网检查新版本，也可以在“模型与更新”页面手动检查。
- 加强本机转写接口的来源限制，仅允许 HearNotes 的 Tauri 页面访问。
- 更新系统架构文档和发布元数据。

### 安装与更新

- 已安装 1.0.2：启动软件后按照“模型与更新”中的提示下载安装。
- 首次安装：下载下方的 `HearNotes_1.1.0_x64-setup.exe` 并运行。
- 软件更新使用数字签名验证，用户电脑不需要 GitHub Token。

## English

This release is intended to verify the complete automatic update flow from HearNotes 1.0.2 to 1.1.

### Changes

- The desktop UI now uses bundled Tauri assets, fixing application update commands that could not be invoked from the local HTTP page.
- HearNotes checks for new versions at startup by default, with a manual check available under “Models & Updates.”
- Access controls for the local transcription API are strengthened so only the HearNotes Tauri page is accepted.
- The system architecture documentation and release metadata are updated.

### Installation and update

- Existing 1.0.2 installation: Start HearNotes and follow the prompt under “Models & Updates.”
- New installation: Download and run `HearNotes_1.1.0_x64-setup.exe` below.
- Application updates are verified with a digital signature. No GitHub token is required on user computers.
