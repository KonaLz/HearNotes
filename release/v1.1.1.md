# HearNotes 1.1.1 / 听记 1.1.1

## 中文

### 更新内容

- 增加软件更新进度弹窗，显示下载百分比、已下载大小、总大小和下载速度。
- 在弹窗中显示检查版本、下载、签名验证、关闭后台和启动安装程序等阶段。
- 修复更新安装时 `hearnotes-engine.exe` 仍被占用的问题。
- 安装前结束转写引擎及其 worker 进程树，并等待文件句柄释放后再启动安装程序；安装器也会清理由旧版本发起更新时残留的引擎进程。
- 更新多语言界面文字和系统架构文档。

### 安装与更新

- 已安装旧版本：进入“模型与更新”检查更新，然后按照提示下载安装。
- 首次安装：下载下方的 `HearNotes_1.1.1_x64-setup.exe` 并运行。
- 软件更新使用数字签名验证，用户电脑不需要 GitHub Token。

## English

### Changes

- Added an application update progress dialog showing percentage, downloaded size, total size, and transfer speed.
- The dialog shows each stage: version check, download, signature verification, background shutdown, and installer launch.
- Fixed update installation failures caused by `hearnotes-engine.exe` remaining locked.
- The transcription engine and its worker process tree are stopped before installation, and HearNotes waits for file handles to be released before launching the installer. The installer also cleans up an engine left behind by an update started from an older version.
- Updated multilingual interface text and the system architecture documentation.

### Installation and update

- Existing installation: Check for updates under “Models & Updates,” then follow the download and installation prompt.
- New installation: Download and run `HearNotes_1.1.1_x64-setup.exe` below.
- Application updates are verified with a digital signature. No GitHub token is required on user computers.
