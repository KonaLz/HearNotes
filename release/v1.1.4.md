# HearNotes 1.1.4 / 听记 1.1.4

## 中文

本版本修复桌面版导出，并补齐转写结果中的多语言提示。

- 点击导出后打开 Windows 原生“另存为”窗口，可选择保存位置和文件名。
- 支持 TXT、Markdown、SRT、JSON 四种格式；取消保存不会生成文件。
- 修复导出 IPC 参数丢失导致的“导出失败”。
- 警告栏、逐段待核标记和校验错误会随中文、日文、英文界面显示。

### 安装与更新

- 已安装旧版本：在“模型与更新”中检查并安装 1.1.4。
- 首次安装：下载下方的 `HearNotes_1.1.4_x64-setup.exe` 并运行。
- 语音转写和说话人分离模型仍需在软件内单独下载。

## English

This release fixes desktop exports and completes localization for transcription result messages.

- Export now opens the native Windows Save As dialog so you can choose the destination and filename.
- TXT, Markdown, SRT, and JSON are supported; cancelling the dialog creates no file.
- Fixed the lost IPC arguments that caused “Export failed”.
- Warnings, review flags, and validation errors follow the Chinese, Japanese, or English interface.

### Install and update

- Existing installation: Check for version 1.1.4 under Models & updates.
- New installation: Download and run `HearNotes_1.1.4_x64-setup.exe` below.
- Transcription and speaker-separation models are still downloaded separately inside the app.
