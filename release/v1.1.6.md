# HearNotes 1.1.6 / 听记 1.1.6

## 中文
- 修复 1.1.5 安装包误用旧版后台引擎，导致导出说明仍显示中文的问题。
- TXT 和 Markdown 的说明、待核提示跟随中文、日文或英文界面语言。
- 打包前自动重建后台引擎，构建失败时停止打包。
- 新增一键签名命令 `npm run release:sign`，生成安装包签名及更新清单。

## English
- Fixed a stale backend engine bundled in 1.1.5 that left exported annotations in Chinese.
- TXT and Markdown notes and review flags follow the Chinese, Japanese, or English interface language.
- Rebuild the backend before packaging and stop packaging if the engine build fails.
- Added `npm run release:sign` to generate the installer signature and updater manifest.
